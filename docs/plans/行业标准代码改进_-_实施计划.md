## Phase 2: Playwright API 兼容性修复 🔧

### 2a. `captchaSolver.ts` — screenshot encoding

Playwright 的 `element.screenshot()` 不支持 `{ encoding: 'base64' }`，返回 `Buffer`。

#### [MODIFY] [captchaSolver.ts](file:///Users/yuu/Downloads/vibe_coding/aycd/aycd-project/src/bot-engine/captchaSolver.ts)

```diff
-const screenshot = await element.screenshot({ encoding: 'base64' });
-return screenshot as string;
+const buffer = await element.screenshot();
+return buffer.toString('base64');
```

### 2b. `waitForLoadState` timeout 参数签名

Playwright 的 `page.waitForLoadState(state)` **不接受 options 对象**。timeout 通过 `page.setDefaultTimeout()` 或单独用 `Promise.race` 控制。

#### 影响文件（5 处）

| 文件 | 当前代码 | 修复 |
|------|---------|------|
| `youtube.ts:53` | `waitForLoadState('domcontentloaded', { timeout: 15000 })` | 删除 options |
| `maps.ts:55` | `waitForLoadState('domcontentloaded', { timeout: 10000 })` | 删除 options |
| `news.ts:52` | `waitForLoadState('domcontentloaded', { timeout: 10000 })` | 删除 options |
| `googleAuth.ts:370` | `waitForLoadState('networkidle', { timeout: 15000 })` | 删除 options |
| `googleAuth.ts:514` | `waitForLoadState('networkidle', { timeout: 20000 })` | 删除 options |

## Phase 3: 代码质量加固 🛡️

### 3a. `captchaHandler.ts` — 用 `locator` 替代 `page.$()`

`page.$()` 在 Playwright 中虽然可用，但官方推荐使用 `page.locator()` + `locator.count()` 判断存在性。

#### [MODIFY] [captchaHandler.ts](file:///Users/yuu/Downloads/vibe_coding/aycd/aycd-project/src/bot-engine/captchaHandler.ts)

将 `detectCaptcha` 中多个 `page.$(selector)` 循环改为：
```typescript
const count = await page.locator(selector).count();
if (count > 0) { ... }
```

### 3b. `googleAuth.ts` — 清理 `page.$()`

替换 `waitForAnySelector` 函数中的 `page.$(selector)` 为 locator 模式。

### 3c. `captchaSolver.ts` — `page.type()` → `page.locator().type()`

```diff
-await page.type(inputSelector, solution.text, { delay: 100 });
+await page.locator(inputSelector).type(solution.text, { delay: 100 });
```

## Phase 4: 结构化日志 📋

### [MODIFY] [taskExecutor.ts](file:///Users/yuu/Downloads/vibe_coding/aycd/aycd-project/src/bot-engine/taskExecutor.ts)

当前 `TaskExecutor.log()` 直接拼接时间戳。改进为结构化格式：

```typescript
log(message: string, level: 'info' | 'warn' | 'error' = 'info'): void {
  const line = `[${new Date().toISOString()}] [${level.toUpperCase()}] ${message}`;
  this.hooks.onLog?.(line);
}
```
