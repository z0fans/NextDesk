# 移除黄色重连圈，统一使用蓝色连接样式

用户希望移除 `reconnecting` 状态的黄色圆圈 spinner，改为与 `connecting` 状态一致的蓝色圆圈样式，并将重连信息（次数、错误原因等）以文字形式显示在下方。

## 修改方案

### [MODIFY] [RdpManager.tsx](file:///Users/yuu/Downloads/vibe_coding/rdp_project/NextDesk/frontend/src/components/RdpManager.tsx)

#### 1. 修改 `reconnecting` 状态的 UI（第 1801-1818 行）

**当前**：黄色 spinner + 黄色文字 + 黄色取消按钮
**改为**：蓝色 spinner（与 `connecting` 一致） + 下方灰色文字显示重连信息 + 简洁取消按钮

```diff
-<div className="h-10 w-10 rounded-full border-4 border-amber-500/30 border-t-amber-500 animate-spin" />
-<p className="text-sm text-amber-400 font-medium">{activeTab.errorMsg || 'Reconnecting...'}</p>
-<Button className="border-amber-500/30 text-amber-400 hover:bg-amber-500/10" ...>
+<div className="h-12 w-12 rounded-full border-4 border-cyan-500/30 border-t-cyan-500 animate-spin" />
+<p className="text-sm text-muted-foreground">{activeTab.errorMsg || 'Reconnecting...'}</p>
+<Button variant="outline" size="sm" ...>
```

去除 `bg-black/60 backdrop-blur-sm` 遮罩层，统一为与 connecting 一致的纯净背景。

#### 2. 整理 `friendlyRdpError` 错误映射（第 298-334 行）

当前已有的错误映射已比较完善，无需大改。仅需确认重连时的 `errorMsg` 也使用 `friendlyRdpError` 处理。

当前 `scheduleReconnect`（第 1121 行）设置的是：
```
`Reconnecting (${count}/${MAX_RECONNECT_ATTEMPTS})...`
```
这里只显示重连计数，不包含错误原因。改为同时显示友好的原因：

```diff
-store.updateTabStatus(tabId, 'reconnecting', `Reconnecting (${count}/${MAX_RECONNECT_ATTEMPTS})...`);
+store.updateTabStatus(tabId, 'reconnecting', `Reconnecting (${count}/${MAX_RECONNECT_ATTEMPTS})...\n${friendlyRdpError(reason)}`);
```

## 验证方式

### 手动验证
1. 运行 `npx tauri dev`
2. 连接一个 RDP 服务器，成功连接后手动断开网络 → 应看到**蓝色圆圈**（而非黄色）+ 下方显示 "Reconnecting (1/5)... + 错误原因"
3. 输入错误密码连接 → 应直接显示红色错误框 "Login failed — incorrect username or password."，无黄色圈
4. 确认正常连接流程（蓝色圈）不受影响
