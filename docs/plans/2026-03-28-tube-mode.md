# Tube Mode 一键加速 Implementation Plan

> **For Antigravity:** REQUIRED WORKFLOW: Use `.agent/workflows/execute-plan.md` to execute this plan in single-flow mode.

**Goal:** 实现一键 Tube Mode 加速 — 用户只开一个开关，系统通过全部代理节点同时加速 RDP，GeoIP 自动选择区域调度器。

**Architecture:** 客户端 `rdp_proxy.rs` 检测 Tube Mode 开启后，通过 Aggligator 建立多条链路（每条经不同 Clash SOCKS5 出口）到 VPS 调度器 `tube-server`，调度器聚合后动态连接 RDP 目标。域名内置，GeoIP 自动选区域。

**Tech Stack:** `aggligator` crate (Rust) + `maxminddb` (GeoIP) + Tokio + Clash SOCKS5

```rust
//! Tube Mode: multi-link aggregation for RDP acceleration.

use std::net::IpAddr;
use tokio::io::{AsyncRead, AsyncWrite, AsyncWriteExt};
use tokio::net::TcpStream;
use std::sync::{Arc, Mutex};

// ===== 内置域名 — 发版前修改 =====
const TUBE_DISPATCHERS: &[(&str, &str)] = &[
    ("us",   "tube-us.yourdomain.com:9000"),
    ("asia", "tube-asia.yourdomain.com:9000"),
];
const DEFAULT_REGION: &str = "us";

// GeoIP country code → region mapping
const AMERICAS: &[&str] = &["US","CA","MX","BR","AR","CL","CO","PE","VE"];
const ASIA_PACIFIC: &[&str] = &[
    "CN","JP","KR","SG","HK","TW","IN","TH","VN","MY","PH","ID","AU","NZ",
];

/// Global toggle type
pub type TubeEnabled = Arc<Mutex<bool>>;

/// Resolve which dispatcher to use based on RDP target IP.
/// Returns dispatcher address like "tube-us.yourdomain.com:9000".
pub fn resolve_dispatcher(rdp_host: &str) -> Option<String> {
    let ip: IpAddr = rdp_host.parse().ok()?;

    // Load GeoIP database from app config dir
    let db_path = crate::config::get_user_config_dir()
        .join("Country.mmdb");
    let reader = maxminddb::Reader::open_readfile(&db_path).ok()?;
    let country: maxminddb::geoip2::Country = reader.lookup(ip).ok()?;
    let iso = country.country?.iso_code?;

    let region = if AMERICAS.contains(&iso) {
        "us"
    } else if ASIA_PACIFIC.contains(&iso) {
        "asia"
    } else {
        DEFAULT_REGION
    };

    log::info!("[tube] GeoIP: {ip} → {iso} → region={region}");
    TUBE_DISPATCHERS
        .iter()
        .find(|(r, _)| *r == region)
        .map(|(_, addr)| addr.to_string())
}
```

### Task 4: Implement Aggligator Multi-Link Connection

**Files:**
- Modify: `src-tauri/src/tube.rs`

This is the core logic. Uses real Aggligator API:
- `connect::connect(cfg)` → returns `(Task, Outgoing, Control)`
- `Control::add_io(read, write, tag, user_data)` → adds a TCP link
- `Outgoing::connect()` → establishes aggregated connection

**Step 1: Add `connect_tube` function to `tube.rs`**

```rust
use aggligator::cfg::Cfg;
use aggligator::connect;
use tokio_socks::tcp::Socks5Stream;

/// Build an Aggligator multi-link connection to the dispatcher.
///
/// Flow:
/// 1. Create Aggligator outgoing connection
/// 2. Open N SOCKS5 links (each through Clash, potentially different nodes)
/// 3. Add each link via Control::add_io
/// 4. Call Outgoing::connect() to establish the aggregated stream
/// 5. Send RDP target address as first message (dispatcher protocol)
/// 6. Return the aggregated IO stream
pub async fn connect_tube(
    dispatcher_addr: &str,
    socks_port: u16,
    rdp_dest: &str,
    link_count: usize,
) -> Result<
    impl AsyncRead + AsyncWrite + Unpin + Send,
    Box<dyn std::error::Error + Send + Sync>,
> {
    let cfg = Cfg::default();
    let (task, outgoing, control) =
        connect::connect::<_, _, ()>(cfg);

    // Spawn the aggligator background task
    tauri::async_runtime::spawn(task);

    // Create multiple links through SOCKS5 (Clash load-balances)
    let socks_addr = format!("127.0.0.1:{socks_port}");
    let mut connected = 0usize;

    for i in 0..link_count {
        match tokio::time::timeout(
            std::time::Duration::from_secs(5),
            Socks5Stream::connect(
                socks_addr.as_str(),
                dispatcher_addr,
            ),
        )
        .await
        {
            Ok(Ok(stream)) => {
                let tcp = stream.into_inner();
                let (r, w) = tokio::io::split(tcp);
                if let Err(e) =
                    control.add_io(r, w, (), &[]).await
                {
                    log::warn!("[tube] Link {i} add failed: {e}");
                } else {
                    log::info!("[tube] Link {i} connected");
                    connected += 1;
                }
            }
            Ok(Err(e)) => {
                log::warn!("[tube] Link {i} SOCKS5 err: {e}");
            }
            Err(_) => {
                log::warn!("[tube] Link {i} timeout (5s)");
            }
        }
    }

    if connected == 0 {
        return Err("No links connected".into());
    }
    log::info!("[tube] {connected}/{link_count} links up");

    // Establish the aggregated connection
    let mut io = outgoing.connect().await
        .map_err(|e| format!("aggligator connect: {e}"))?;

    // Protocol: send RDP destination as first line
    // so tube-server knows where to forward
    let header = format!("{rdp_dest}\n");
    io.write_all(header.as_bytes()).await?;

    Ok(io)
}
```

```rust
// 3: TCP connect - Tube Mode or normal
let tube_on = *tube_enabled.lock().unwrap();
let dest_host = dest.split(':').next().unwrap_or(&dest);

if tube_on {
    if let Some(dispatcher) = crate::tube::resolve_dispatcher(dest_host) {
        log::info!("[rdp_proxy] Tube Mode → {dispatcher}");
        match crate::tube::connect_tube(&dispatcher, socks_port, &dest, 3).await {
            Ok(mut tube_io) => {
                // X.224 over tube
                tube_io.write_all(&x224_req).await?;
                let mut buf = vec![0u8; 4096];
                let n = tube_io.read(&mut buf).await?;
                let x224_resp = buf[..n].to_vec();

                // TLS over tube
                let tls_cx = native_tls::TlsConnector::builder()
                    .danger_accept_invalid_certs(true)
                    .danger_accept_invalid_hostnames(true)
                    .build()?;
                let tls_cx = tokio_native_tls::TlsConnector::from(tls_cx);
                let tls = tls_cx.connect(dest_host, tube_io).await
                    .map_err(|e| format!("tls: {e}"))?;
                let chain: Vec<Vec<u8>> = tls.get_ref()
                    .peer_certificate().ok().flatten()
                    .and_then(|c| c.to_der().ok())
                    .map(|d| vec![d])
                    .unwrap_or_default();

                // RDCleanPath response
                let resp = RDCleanPathPdu::new_response(
                    dest.clone(), x224_resp, chain,
                ).map_err(|e| format!("resp: {e}"))?;
                let resp_bytes = resp.to_der()
                    .map_err(|e| format!("enc: {e}"))?;
                tx.send(Message::Binary(resp_bytes.into())).await?;
                log::info!("[rdp_proxy] [TUBE] Response sent, relay");

                // Raw relay over TLS-over-Tube
                let (mut tr, mut tw) = tokio::io::split(tls);
                let w2t = async {
                    while let Some(Ok(m)) = rx.next().await {
                        if let Message::Binary(d) = m {
                            if tw.write_all(&d).await.is_err() { break; }
                        }
                    }
                };
                let t2w = async {
                    let mut b = vec![0u8; 16384];
                    loop {
                        match tr.read(&mut b).await {
                            Ok(0) | Err(_) => break,
                            Ok(n) => {
                                let msg = Message::Binary(b[..n].to_vec().into());
                                if tx.send(msg).await.is_err() { break; }
                            }
                        }
                    }
                };
                tokio::select! { _ = w2t => {} _ = t2w => {} }
                log::info!("[rdp_proxy] [TUBE] Done {dest}");
                return Ok(());
            }
            Err(e) => {
                log::warn!("[rdp_proxy] Tube failed: {e}, fallback normal");
            }
        }
    }
}

// Fallback: normal single-path connection (existing code)
```

```rust
//! tube-server: Aggligator dispatcher with dynamic RDP target.
//!
//! Protocol:
//! 1. Accept Aggligator aggregated connection
//! 2. Read first line = "host:port\n" (RDP target)
//! 3. TCP connect to that target
//! 4. Bidirectional relay

use aggligator::cfg::Cfg;
use aggligator::connect::Server;
use clap::Parser;
use tokio::io::{AsyncBufReadExt, AsyncRead, AsyncWrite, BufReader};
use tokio::net::TcpListener;

#[derive(Parser)]
struct Args {
    #[arg(long, default_value = "0.0.0.0:9000")]
    listen: String,
}

#[tokio::main]
async fn main() -> anyhow::Result<()> {
    env_logger::init();
    let args = Args::parse();

    let server = Server::<_, _, ()>::new(Cfg::default());
    let mut listener = server.listen()?;
    let tcp_listener = TcpListener::bind(&args.listen).await?;
    log::info!("tube-server listening on {}", args.listen);

    // Accept incoming TCP links and feed to Aggligator server
    let srv = server.clone();
    tokio::spawn(async move {
        loop {
            if let Ok((stream, _)) = tcp_listener.accept().await {
                let (r, w) = tokio::io::split(stream);
                if let Err(e) = srv.add_incoming_io(r, w, (), &[]).await {
                    log::warn!("add_incoming: {e}");
                }
            }
        }
    });

    // Accept aggregated connections
    while let Ok(incoming) = listener.accept().await {
        tokio::spawn(handle_connection(incoming));
    }

    Ok(())
}

async fn handle_connection<IO>(io: IO)
where IO: AsyncRead + AsyncWrite + Unpin + Send
{
    if let Err(e) = handle_inner(io).await {
        log::error!("connection error: {e}");
    }
}

async fn handle_inner<IO>(io: IO) -> anyhow::Result<()>
where IO: AsyncRead + AsyncWrite + Unpin + Send
{
    let (reader, writer) = tokio::io::split(io);
    let mut buf_reader = BufReader::new(reader);

    // 1. Read target address from first line
    let mut target = String::new();
    buf_reader.read_line(&mut target).await?;
    let target = target.trim();
    log::info!("connecting to RDP target: {target}");

    // 2. TCP connect to RDP
    let rdp_stream = tokio::net::TcpStream::connect(target).await?;
    let (rdp_r, rdp_w) = tokio::io::split(rdp_stream);

    // 3. Bidirectional relay
    let a2b = tokio::io::copy(&mut buf_reader, &mut rdp_w);
    let b2a = tokio::io::copy(&mut rdp_r, &mut writer);
    tokio::select! { _ = a2b => {} _ = b2a => {} }

    Ok(())
}
```
